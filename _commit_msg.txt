  borrows only. repay, withdraw, claim_yield, and mark_default always work
  while paused -- pausing can never trap anyone's funds, it only stops new
  risk from being taken.
- admin-adjustable global deposit_cap per agent vault (capital at risk =
  liquidity + principal), caps the blast radius of an undiscovered bug.
  0 = uncapped (existing tests use 0 so behavior is unchanged).

  drives 5 seeds x 300 random deposit/borrow/repay/withdraw/claim_yield calls
  each, asserting after every single call that
  token.balance(vault) == liquidity + reserve + yield_pool.
  1500 checks, zero breaks.
